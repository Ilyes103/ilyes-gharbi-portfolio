# Ilyes Gharbi — Engineering Portfolio

Personal engineering portfolio of **Ilyes Gharbi**, Electrical Engineer specialized in Embedded Systems, Automotive Cable Harness Manufacturing, Industrial Automation, and Smart Factory Telemetry.

---

## Overview

Electrical Engineer with hands-on experience in the automotive wiring harness industry (SEBN Jendouba) and industrial telemetry projects. Specialized in:

- **Embedded Systems**: STM32, ESP32, FreeRTOS, Embedded C/C++, Hardware Abstraction Layer (HAL).
- **Industrial Automation**: PLCs, Siemens TIA Portal, SCADA dashboards, Node-RED, HMI interfaces.
- **Industrial IoT & Telemetry**: CAN bus, Modbus RTU / TCP, Mosquitto MQTT, OPC UA.
- **Robotics & Vision**: ROS2, LiDAR SLAM navigation, Gazebo simulation, OpenCV vision.
- **Automotive Systems**: Wiring harness assembly, quality optimization, process improvement, Six Sigma.

---

## Technical Stack & Architecture

### Web Application Architecture
- **Framework & Core**: React 19, TypeScript, Vite 8
- **Styling & System**: Tailwind CSS v4, Custom Industrial Dark Mode System
- **Icons & Visual Components**: Lucide React, Custom Hardware Pipeline SVGs
- **Motion & Accessibility**: Asynchronous IntersectionObserver reveals, hardware-accelerated CSS transitions, full `prefers-reduced-motion` compliance.

## Featured Projects

1. **Autonomous Robot & Robotic Arm for Product Handling & Storage (ROS2 / Industry 4.0)**
   - Final Year Engineering Project conducted at SEBN Jendouba.
   - Built a ROS2 and LiDAR autonomous mobile robot (AMR) integrated with a 6-DOF robotic arm for product handling and storage, supervised via a custom React Native mobile app.

2. **Smart Factory Environmental Monitoring System (Industrial IoT / SCADA)**
   - Developed an Industry 4.0 IoT telemetry system using ESP32 nodes, Mosquitto MQTT brokers, and Node-RED SCADA dashboards for real-time plant safety.

3. **STEG Gas Pressure Regulating Station Telemetry (Industrial IoT / SCADA)**
   - Embedded monitoring system supervising gas pressure, thermal metrics, and safety interlocks for STEG gas distribution equipment.

4. **Automotive Cable Harness Production Optimization (Process Improvement / SEBN Jendouba)**
   - Workflow analysis and line optimization in automotive wiring harness manufacturing applying process improvement methodologies and Six Sigma Yellow Belt frameworks.

## Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/ilyes-gharbi/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

---

## Production Build & Static Analysis

```bash
# Build production bundle with TypeScript verification
npm run build

# Run static analysis & linting
npm run lint

# Preview production build locally
npm run preview
```
